# ديوان اليوم 📜

قصيدةٌ لشاعرٍ مهمّ كلّ يوم، عبر كلّ العصور (جاهليّ، مخضرم، أمويّ، عباسيّ، أندلسيّ، نهضة، حديث/معاصر) —
شعرٌ عموديّ حقيقيّ، مع شرح غريب الكلام ومعنى الشاعر ومقصده بأسلوب مبسّط.
